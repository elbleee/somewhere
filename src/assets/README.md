# Asset pipeline

Production art is stored here by layer, not baked into full-screen mockups.

- `surfaces/` — desk and tabletop textures
- `environments/` — collection scene backgrounds
- `folders/` — reusable folder and collection objects
- `paper/` — blank paper stocks and stationery
- `accessories/` — reusable desk objects with alpha transparency
- `clocks/` — clock faces, hands, and frames as separate layers
- `lighting/` — overlays and light treatments

The first visual target is the Clean & Textured theme. Each asset must be high-resolution, sharply focused, mobile-composed, and independently reusable. Avoid baked-in labels, shadows, or checkerboard backgrounds where those effects belong in code.
